# Identifying Loss-Making Products Using Sales Data | Excel

## Project Overview
Analyzed sales data using Microsoft Excel to identify loss-making products, understand profitability, and evaluate the impact of discounts on business performance.

## Key Activities
- Analyzed sales, cost, discount, and profit data to identify products and categories contributing to lower profitability.
- Cleaned and structured sales data and created calculated fields including Total Cost, Discount Amount, Profit, and Profit Margin.
- Built an interactive Excel dashboard with KPI cards and filters to monitor sales, profitability, product performance, and discount patterns.
- Identified products with high sales but low profit and areas where discount levels affected profitability.

## Tools & Skills
- Microsoft Excel
- Data Cleaning
- Pivot Tables
- Excel Formulas
- KPI Development
- Interactive Dashboard
- Business Data Analysis

## Key Business Insights
- Identified high-sales products with comparatively low profitability.
- Analyzed discount patterns and their impact on profit margins.
- Evaluated category-wise sales and profitability performance.

## Project Outcome
Developed an interactive dashboard to support data-driven decisions and improve product profitability analysis.
